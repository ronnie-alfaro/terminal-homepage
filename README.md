# Ronnie Alfaro Terminal Portfolio

Personal CV/portfolio site built as an interactive terminal with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The generated `dist/` directory can be hosted as a static site with nginx, Cloudflare Pages, GitLab Pages, Netlify, or any static file host.

## Docker

```bash
docker compose up --build -d
```

The site will be available on port `8181`.

For remote server setup, see [DEPLOY_REMOTE.md](./DEPLOY_REMOTE.md).
